

1. What is a Resource Request?
A request is the amount of CPU or memory Kubernetes reserves for a container when deciding which Node (server) should run it on.

For example:
- CPU request: 500m (half a CPU core)
- Memory request: 256Mi (256 MiB of memory)



2. What is a Resource Limit?
A limit is the maximum amount of CPU or memory a container is allowed to use.

For example:
- CPU limit: 1 (one CPU core)
- Memory limit: 512Mi (512 MiB of memory)
