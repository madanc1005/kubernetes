Secrets
In Kubernetes, a Secret is an object used to store sensitive information, such as passwords, usernames, API tokens, and database credentials


1. Why do we need Secrets?
            Imagine you have a web application running inside a Kubernetes Pod. Your application needs to connect to a MySQL database.
            To connect, it needs a username and password.

                                Web Application
                                Running inside a Kubernetes Pod
                                        |
                                Kubernetes Secret
                                Database username and password
                                        |
                                MySQL Database
                                Authenticates the application


2. What information can a Secret store?
                Examples include:
                - Database usernames and passwords
                - Docker registry credentials
                - API keys
                - Authentication tokens
                - TLS certificates and private keys

4) create a pod and mount it 
            apiVersion: v1
            kind: Pod
            metadata:
            name: my-app
            spec:
            containers:
                - name: app
                image: nginx
                volumeMounts:
                    - name: secret-volume
                    mountPath: /etc/db-secret
                    readOnly: true
            volumes:
                - name: secret-volume
                secret:
                    secretName: my-secret
