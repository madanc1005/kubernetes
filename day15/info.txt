1)  first we have to create the role.yml use kubectl api-resources

        apiVersion: rbac.authorization.k8s.io/v1
        kind: Role 
        metadata:
          name: obito-role
        rules: 
        - apiGroups: [""]
          resources: ["pods"]
          verbs: ["get", "watch", "list"]
    
    run the above yml file

2)  now ned to create role binding yml file 

        apiVersion: rbac.authorization.k8s.io/v1
        kind: RoleBinding
        metadata:
        name: obito-role-binding
        subjects: 
        - kind: User
        name: obito
        apiGroup: rbac.authorization.k8s.io
        roleRef:
        kind: Role
        name: obito-role
        apiGroup: rbac.authorization.k8s.io

    run the above yml file
