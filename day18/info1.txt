Network policies

Network policies are rules that control who can communicate with whom over a network and what communication is allowed or blocked.

CNI stands for Container Network Interface. It is used in Kubernetes to provide network connectivity to containers and Pods.

apiVersion: v1
kind: Pod
metadata:
  name: frontend-pod
  labels:
    role: frontend-role
spec:
  containers:
  - name: frontend-container
    image: nginx
    ports:
    - name: http
      containerPort: 80
      protocol: TCP

---
apiVersion: v1
kind: Service
metadata:
  name: frontend-service
  labels:
    role: frontend-service-role
spec:
  selector:
    role: frontend-role
  ports:
  - protocol: TCP
    port: 80
    targetPort: 80
